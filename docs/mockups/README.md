# 見た目のモックアップ（アーカイブ）

2026-10-11 にユーザーと見比べて合意した見た目（design-spec 4.4 の月相）のモックアップ。レイアウトのパターンごとに1画面ずつ、11画面ある。PR #4 で、この見た目を design-spec と `06_design-tokens.json` に書き写した。

元のファイルは使い捨ての HTML で、手元から消えていた。2026-10-17 に、作ったセッションの記録から、書いた操作と直した操作を時刻の順に当て直して復元した。

## 扱い

- 更新しない。値と形の正は `design-spec.md` と `06_design-tokens.json`。
- 2026-10-17 に、部品（`packages/ui-web`）がこのモックアップと違うことが分かり、ユーザーの決定で docs と部品をモックアップに合わせ直した（`claude-code-prompts.md` の Step 22c〜22e・22h・22i）。モックアップと違っていても docs に残したもの（アクセシビリティの決まり、全部大文字にしない見出し、Pitch Deck の印刷の文字と寸法、後の日付の決定、モックアップが省いていても省くと機能や情報が減るもの）は、`design-spec.md` のそれぞれの節に書いてある（決めた経緯は `claude-code-prompts.md` の Step 22c と 22h）。
- 画面を作るときと直すときは、該当の画面をこのモックアップと並べて見た目を確かめる。モックアップは見た目のイメージで、ピクセル単位で合わせることは目的にしない。並べて見れば測らなくても分かる違い（並び・色・文字の階層・部品の形・文の幅と折り返し・崩れ）は残さず、数 px の余白や高さ・0.5〜1px の文字の大きさ・アイコンの 2px・太さの 500 と 600 のような違いは追わない（2026-10-18 のユーザーの決定。範囲の正は `design-spec.md` 4.5）。

## 開き方

静的なサーバーで配って開く（書体は Google Fonts から読むので、ネットが要る）。

```sh
python3 -m http.server 5391 --bind 127.0.0.1 -d docs/mockups
```

`http://localhost:5391/screens.html` で11画面を切り替えられる。各画面のファイルは `?theme=light` か `?theme=dark` を付けて開く。幅は 1440 と 390 で確かめた。
